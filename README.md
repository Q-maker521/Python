# Python / FastAPI 学习项目

## 当前状态（2026-11-08）
- 已实现异步工具注册与分发、日志和计时装饰器。
- 已实现 JSON 校验、单次执行 2 秒超时及取消处理。
- FastAPI 提供健康检查、请求预览、工具执行和带超时执行接口。
- 带超时接口在单进程内共享 Semaphore(2)，排队不计入执行超时。
- 已通过 HTTP 客户端并发发送 5 个请求：4 个成功、1 个超时，总耗时约 3.108 秒（手工运行验证）。
- 当前业务错误与超时仍返回 HTTP 200；普通执行接口未使用并发限制。

## 运行
在项目根目录、已安装依赖的虚拟环境中：

```powershell
python -m uvicorn demo_fastapi.main:app --reload
```

保持服务运行，在另一终端执行：

```powershell
python demo_fastapi/test_http_concurrency.py
```
